# 4. Worker Dashboard Module

## 4.1. Purpose

The Worker Dashboard is the central hub for workers to manage their professional identity, apply for jobs, and track their application status.

## 4.2. Core Feature: The "Skill Passport"

The primary feature is the worker's profile, referred to as their "Skill Passport." This is their digital resume and the key to getting matched with employers.

### 4.2.1. Firebase Integration

*   **Data Storage:** All profile information is stored in a document within the `workerProfiles` Firestore collection.
*   **File Storage:** Profile photos and CV documents are uploaded to **Firebase Storage**. The public URL generated by Firebase Storage is then stored in the `photo_url` and `cv_url` fields of the worker's profile document.

### 4.2.2. Profile Management Flow (CRUD)

1.  **Create:** If a new worker has no profile, the dashboard presents a "Create Your Profile" call-to-action. Clicking it opens a form.
2.  **Read:** Once a profile is created, the dashboard displays the "Skill Passport" in a clean, read-only view, highlighting key information.
3.  **Update:** An "Edit Profile" button allows the worker to open the form again, pre-populated with their existing data, to make changes.
4.  **Delete:** (No delete functionality for users. Account deletion should be a separate, deliberate process).

### 4.2.3. Profile Fields

The profile form and display MUST include all fields from the `WorkerProfile` interface:
*   `full_name` (text input)
*   `trade_or_skill` (text input)
*   `experience_years` (number input)
*   `summary` (textarea)
*   `country_of_origin` (dropdown select)
*   `experience_in_country` (number input)
*   `photo_url` (file input with image preview)
*   `cv_url` (file input, shows file name or download link)

## 4.3. Future Feature: My Applications

*   A section on the dashboard will list all jobs the worker has applied for.
*   This will require a new `applications` collection in Firestore.
*   The view will show the job title, company, and the status of the application (e.g., 'Submitted', 'Viewed', 'Shortlisted').
